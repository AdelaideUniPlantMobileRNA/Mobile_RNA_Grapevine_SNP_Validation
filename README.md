## 2. Directory structure
```
project/
├── README.md                 <- this file (start here)
├── environment.yml           <- conda environment (exact tool versions)
├── .gitignore                <- what git must NOT track (data, results, env)
├── config/                   <- parameters & paths (NO hard-coded paths in scripts)
│   └── config.yaml
├── docs/                     <- human-readable documentation
│   ├── experiment_background.md   <- biology, hypothesis, design, wet-lab notes
│   ├── analysis_log.md            <- dated log of what you ran and why
│   └── decisions.md               <- key method decisions + rationale
├── metadata/                 <- sample sheets, accessions (version-controlled)
│   └── sample_sheet.tsv
├── data/
│   ├── raw/                  <- READ-ONLY original data (never edit; chmod a-w)
│   ├── external/             <- reference genomes, annotations, databases
│   └── processed/            <- intermediate files generated by code
├── scripts/                  <- numbered, ordered analysis steps
│   ├── 00_setup.sh
│   ├── 01_trim.sh
│   ├── 02_align_star.sh
│   └── R/                    <- R scripts / functions
├── workflow/                 <- Snakemake/Nextflow pipeline (optional but recommended)
├── results/                  <- final tables, stats (regenerable; not in git)
├── figures/                  <- final figures for thesis/paper
└── logs/                     <- SLURM logs, tool stderr/stdout
```
